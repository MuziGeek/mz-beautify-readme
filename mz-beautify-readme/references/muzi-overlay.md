# Muzi Visual Overlay

Apply this file only after the pinned upstream core has locked scope, content architecture, proof, theme intent, composition, implementation, dimensions, responsiveness, and motion policy.

## Boundary

The Overlay may change:

- brand tokens: warm paper, ink, mustard yellow, navy, and restrained rust red;
- rendering texture: crayon edges, paper grain, handmade annotations, and slightly irregular SVG strokes;
- a locally verified `PF频凡胡涂体` (`PFanHuTuTi`) candidate for a short expressive display title;
- Muzi, one subordinate cat, and project-native hand-drawn metaphors when they have a communication job.

The Overlay may not change:

- README information order, project claims, proof selection, or first successful action;
- the upstream composition or SVG/Hybrid/Raster choice;
- project-native typography judgment when an expressive display face is unsuitable;
- Hero dimensions, proportions, responsive strategy, proof count, or motion authorization;
- GitHub safety, accessibility, preview, review, publication, or attribution rules.

The contract is: `core(project) == core(project + Muzi)`. Only `overlay` fields and visual tokens may differ.

## Application rules

- `PFanHuTuTi` is optional, Muzi-only, display-only, and local-build-only. Verify source and permission; never bundle it. Fall back to the project-native face when missing or unsuitable.
- Muzi appears only to inspect, compare, connect, build, test, explain, or guide attention. He is not a corner mascot.
- A cat requires Muzi, stays visibly subordinate, carries no label or process responsibility, and is excluded from dense or strict technical diagrams.
- Use project proof before illustration. Illustration may frame proof but may not fabricate it.
- In a one-board Hybrid hero, generated material and real proof must read as one continuous scene. Prefer matched paper, transparent foreground extraction, or one shared environmental plane. Do not wrap proof in a floating white card unless the repository's real artifact is itself a card or the locked upstream composition explicitly requires one.
- When the core chose `split`, a single project-specific divider preset may clarify zones. Do not impose fixed `x=500` or `y=365` coordinates on other projects.
- When the core chose `integrated`, `artifact-wall`, `background-proof`, or `title-only`, preserve that relationship. Do not simulate a split with background rectangles.

## Reference-image interpretation

The Oil Motion reference is not a universal Muzi template. The upstream core decision is `Split + Hybrid one-board hero`; Oil's personal layer adds the character, dog, yellow emphasis, filmstrip, and hand-drawn line quality. Muzi follows the same dependency direction: first keep the upstream decision, then substitute only the personal visual language.
